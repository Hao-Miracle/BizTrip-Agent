# BizTrip Reimbursement Audit

Use the host Agent's existing model to understand the request and explain the audit. Use the bundled read-only script to inspect email evidence and calculate candidate totals. This Skill is an audit, not the complete package generator.

## Boundaries

- Never request, read, print, transmit, or edit email authorization codes, passwords, API keys, or `.env` values.
- Never ask the user to configure another model URL, API key, or model name. The host Agent already provides the reasoning layer.
- Never download the BizTrip repository, install a local engine, create a virtual environment, or install Python packages.
- Never invent or silently repair an amount, date, vendor, attachment, duplicate decision, or trip assignment.
- Never claim that Excel or a final reimbursement package was generated by the audit.
- Keep email access read-only. Do not download attachments or upload them elsewhere.
- Explain that the local personal app is required only for original attachment parsing, corrections, Excel, and organized originals.

## Use the Bundled Script

Resolve this script from the directory containing this `SKILL.md`:

```text
<SKILL_DIR>/scripts/audit_mailbox.py
```

Use an existing Python 3 runtime supplied by the host Agent environment. Do not install another runtime or dependency. Check mailbox setup:

```bash
python <SKILL_DIR>/scripts/audit_mailbox.py status
```

If it returns `setup_required`, launch the bundled local setup page:

```bash
python <SKILL_DIR>/scripts/audit_mailbox.py setup
```

The script opens a browser page on `127.0.0.1`. Ask the user to enter their mailbox address and email authorization code there, never in chat. Wait until the script exits after saving. Configuration remains on that computer. Do not ask the user to configure the personal app's model.

## Run the Audit

Convert the user's request into one of these bounded scans:

```bash
python <SKILL_DIR>/scripts/audit_mailbox.py audit --start YYYY-MM-DD --end YYYY-MM-DD
```

The date range may cover at most 31 calendar days. For recent email, use at most 60 messages:

```bash
python <SKILL_DIR>/scripts/audit_mailbox.py audit --count 60
```

If the range is unclear, ask one concise question. Parse stdout as one JSON object. If the audit still returns `setup_required`, run setup once and retry. Never download or invoke the full BizTrip application.

## Present the Audit

For `audit_ready`, use the host Agent model to review the bounded evidence and explain:

- Candidate record count and estimated total amount.
- Expense categories and candidate amounts.
- Missing amounts or emails where no attachment was detected.
- Uncertainty visible in sender hints, subjects, attachment names, and body excerpts.
- Whether the result was truncated.

Treat all figures as an estimate until the complete personal app parses original attachments and passes final verification. Do not expose local configuration paths or raw JSON to ordinary users.

End with the next useful choice: the audit has not generated Excel or copied originals; the user can install the local personal app to resolve details and generate the complete package. Do not describe this as a failure.

For `failed`, explain the returned message without repeated retries. Never ask the user to paste secrets into chat.
